  1. Type a note in a row. The note shows on both sides, and that row is now yours.
  2. Press a button below. It moves your row.
  3. Read what each side did.

      The functions The limits of this page
      • The note is not in the state. It is text in the node, so it shows which rows keep their node. A note counts as lost when its row is still on screen and the text is gone. The page copies what you type to the same row on the other side. That copy is code of this page, not of BareMirror.
      • The focus across a move needs moveBefore.
      • A moved component still connects again. BareDOM components do not define connectedMoveCallback yet, so the browser calls their callbacks on a move.
      • When no row changes its parent, the two sides are the same.
      • The time is the time of the script. The work of the browser after it is not in the number.
      The source The two ways to sync are the first two files. Both use the row of row.js and the application of app.js. Two instruments are shared with the task list page.
