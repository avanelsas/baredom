x-floating-panel

Non-modal container that floats above page content. Drag the handle bar to move it, or focus the handle and use the arrow keys (Shift + arrow for 1px precision). Sits below modals and toasts by design.

API
show() hide() toggle() Reset position Clear log
Live Controls
Apply step
Cancelable dismissal

Scroll or resize the window: the panel is positioned against the viewport, so it stays put while this content moves, and it is re-clamped into view whenever the viewport shrinks. Try dragging it mostly off the left edge — a strip stays reachable rather than letting it escape entirely.
